# Clients

Per-client JSON configuration files live here, one file per client (e.g.
`mcfie-insurance.json`), matching the "Client Schema" in the Foundation Docs:
company, website, industry, products, competitors, brand voice, tone, SEO
keywords, avoid words, and prompt templates.

No client files exist in this repository yet — see `backend.models.client`
and `backend.models.brand_profile` for the schema these files should match
once added.
